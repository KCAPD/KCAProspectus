# KCA Digital Prospectus — V1

A static, mobile-first digital prospectus for King's Cross Academy.

## Deploy to GitHub Pages
Upload the contents of this folder to the root of a GitHub repository, then enable GitHub Pages from the main branch/root.

## Files
- index.html — page content
- style.css — responsive design
- script.js — mobile navigation
- assets/ — supplied KCA photography, logo and values characters

V1 intentionally includes placeholders in “What do others say about us?” for later parent/pupil/external evidence.
